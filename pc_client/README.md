# XASS для Windows

Это полноценное ПК-приложение XASS: оно подключает компьютер к серверу, показывает состояние соединения и логи, отправляет метрики и автоматически устанавливает подписанные обновления клиента. Версия 0.12 добавляет системный трей, отдельные разделы архива/обновлений/диагностики, single-instance защиту и атомарное восстановление конфигурации.

## Установка

Обычному пользователю Python и ручная установка зависимостей не нужны:

1. В Telegram Mini App откройте «Устройства» → «Добавить ПК».
2. Нажмите «Скачать» в блоке «XASS для Windows» и запустите `XASS-Setup.exe`.
3. Скачайте файл `xass-connect.xass` и откройте его двойным щелчком — установленный XASS заполнит адрес сервера и одноразовый ключ автоматически.

Установщик ставит XASS для текущего пользователя, добавляет приложение в меню «Пуск» и список установленных приложений Windows, регистрирует файлы `.xass`, предлагает ярлык на рабочем столе и включает автозапуск. Настройки и ключ хранятся в `%LOCALAPPDATA%\XASS`, поэтому обновление приложения их не стирает.

## Быстрый запуск из исходников

1. В Telegram Mini App откройте «Агенты» → «Подключить ПК» или получите код командой `/pairpc`.
2. Запустите `run_agent.bat` — откроется окно XASS.
3. На вкладке «Подключение» введите URL/IP сервера, код привязки и имя ПК.
4. Нажмите «Сохранить и подключить».

Первый запуск полностью автоматический: если Python 3.11+ отсутствует, XASS попробует установить Python 3.12 через `winget`, затем создаст `.venv` и установит `httpx`/`psutil`. При последующих запусках зависимости проверяются по хешу `requirements.txt` и переустанавливаются только после их изменения.

Клиент получит персональный ключ и сохранит настройки в локальном `config.json`.

### Подключение одним файлом

1. В Mini App откройте «Агенты» → «Подключить ПК».
2. При необходимости исправьте публичный адрес/IP сервера.
3. Нажмите «Скачать файл подключения» и перенесите `xass-connect.xass` на компьютер.
4. Откройте файл двойным щелчком либо в окне XASS выберите «Подключение» → «Выбрать файл».

Приложение проверит формат и срок действия, заполнит адрес и одноразовый ключ, а затем само выполнит pairing. Постоянного API-ключа в скачиваемом файле нет: он выдаётся сервером только после успешной привязки и сохраняется локально в `config.json`.

В окне приложения доступны:

- запуск, остановка и перезапуск фонового агента;
- состояние соединения и версия клиента;
- живой журнал heartbeat;
- ручная проверка обновлений;
- автоматическое безопасное обновление установленной программы с проверкой подписи, размера и SHA-256;
- cache-busting, реальный прогресс в байтах, единый межпроцессный lock и автоматический откат;
- UTF-8 журнал и экспорт диагностического отчёта без ключей и приватных сообщений;
- удалённая блокировка рабочего стола из Telegram Mini App.

Разблокировка выполняется только локально средствами Windows — PIN-кодом, паролем или Windows Hello. Удалённого обхода экрана входа XASS не предоставляет.

## Фоновый запуск без окна

```bat
run_headless.bat --server-url http://1.2.3.4:8001 --pair-code XXXX-YYYY
```

Если используется домен, например `https://redvps.site`, клиент попробует найти backend по `/health` и стандартным портам `8001/8000`.

Дополнительный пример:

```bat
run_headless.bat --server-url http://1.2.3.4:8001 --pair-code XXXX-YYYY --source-name OFFICE-PC --interval-sec 20
```

Для старого режима с общим ключом:

```bat
run_headless.bat --server-url http://1.2.3.4:8001 --api-key YOUR_AGENT_API_KEY
```

## Автозагрузка Windows

- Установить: `install_autostart.bat`
- Удалить: `uninstall_autostart.bat`

Автозагрузка запускает XASS свёрнутым. Фоновый агент автоматически поднимается после перезапуска и обновления.

## Сборка установщика

На Windows запустите из корня репозитория:

```powershell
powershell -ExecutionPolicy Bypass -File .\pc_client\build_installer.ps1
```

Скрипт создаёт отдельное окружение сборки, устанавливает зависимости, собирает приложение PyInstaller и выпускает `pc_client\dist\installer\XASS-Setup.exe` через Inno Setup. В GitHub Actions тот же процесс запускается автоматически при изменении `pc_client`; готовый установщик и его SHA-256 публикуются на сервере в `data/releases`.

## Как выпускать обновления

1. Обновите файлы в серверной папке `pc_client`.
2. Измените версию в `version.json`, например `0.4.3` → `0.4.4`.
3. Перезапустите backend.

Для установленной версии CI собирает новый `XASS-Setup.exe`, вычисляет SHA-256 и публикует его на сервер. Сервер подписывает манифест персональным ключом агента; клиент проверяет подпись и контрольную сумму, запускает тихое обновление и снова открывает XASS. Запуск из исходников по-прежнему получает ZIP-обновление. В Mini App можно принудительно отправить команды «Обновить», «Перезапустить» или «Заблокировать».

Чтобы выключить автоматическую установку на конкретном ПК, задайте в `config.json`:

```json
{"auto_update": false}
```

## Что отправляет агент

- CPU, RAM, диск, сеть и uptime;
- now playing, если доступно в ОС;
- активное окно/приложение на Windows;
- top-процессы, если опция включена.

Секретный ключ и `config.json` не входят в серверный пакет обновления.
