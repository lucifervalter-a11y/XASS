# XASS 0.15 — интерфейс Windows и достоверный статус

## Что изменилось

Windows получил новую графитовую оболочку: боковую навигацию с монохромными иконками, домашний экран с фирменным изображением, живыми метриками и карточками действий, общие скруглённые компоненты, новые экраны подключения, команд и обновлений. Сохранены агент, архив, файлы, журнал, настройка и проверка обновлений; интерфейс не заменён статичной картинкой.

Сводка Mini App больше не считает все непрочитанные уведомления текущими неисправностями. Текущие проблемы группируются по сервису/устройству, обновления и уведомления для разбора вынесены отдельно. Неизвестная доступность не отображается ни как offline, ни как фиктивные 100%.

Адрес публичного сайта без схемы нормализуется в HTTPS. Ошибки HTTP, TLS, отказ соединения и незавершённые проверки различаются. История уведомлений не удаляется. Кнопка открытия Mini App в Windows использует канонический публичный адрес backend, а не переносит внутренний порт агента в ссылку.

## Дизайн и визуальная проверка

- [Концепт](assets/xass-desktop-concept.png), 1586×992: DSX использован как пример композиции и плотности, без его бренда и функций контроллеров.
- [Реальное приложение](assets/xass-desktop-overview.png): захват Windows через Computer Use, не браузерная имитация. Окно 1520×940; захват при системном DPI возвращает 1218×783 логических пикселя с рамкой. Поэтому пиксельное сравнение с размером макета не эквивалентно.
- Оба изображения просмотрены через `view_image` в одном финальном проходе. Сопоставлены структура, тексты и порядок навигации, иерархия Segoe UI, графитовая палитра, сине-сиреневый акцент, размер и смысл иконок, рамка и положение hero, карточки и интервалы.
- Главная, компьютер, подключение, команды, файлы, архив, журнал, обновления и настройки проверены в настоящем окне. При 900×680 проверены перенос карточек, полный заголовок, формы и прокрутка; переход по подписи карточки открывает нужный раздел.
- Mini App проверена через Playwright Chromium (320, 390 и 1280) и WebKit (390). Browser plugin отсутствовал в доступном каталоге навыков; native Windows-приложение в браузере не запускается. Проверены unknown → HTTP 503 → healthy, отсутствие Telegram-конфигурации, раскрытие подробностей и сохранение раскрытия после обновления. Переполнения по горизонтали и ошибок приложения в консоли не найдено.

| Сравнение | Результат и исправления |

Реализация визуально сверена с концептом и сохраняет его композицию и дизайн-систему. Намеренные отличия: настоящий системный заголовок Windows вместо рисованного; выбранный ранее логотип сохранён; более контрастный тёмный текст primary-кнопок; реальные показатели вместо демонстрационных; нейтральное состояние предпросмотра и пустой журнал вместо выдуманного соединения. Новых продуктовых разделов из DSX не добавлено.

## Техническая проверка и ограничения

Автотесты покрывают статусы и группировку уведомлений, общую ограниченную по времени проверку сайта, отмену ожидания, безопасные ссылки, PWA-кэш, управление агентом, обновления и адаптивные Tk-компоненты. Локальная сборка Inno Setup завершилась; frozen `XASS.exe --health-check --expected-version 0.15.0` прошёл, новые модули, hero и Tcl/Tk присутствуют. Публиковать следует чистую CI-сборку, а не локальный dirty-артефакт.

Тестовое окно запускалось с `--preview`: оно не подключает агент к серверу. Установщик на пользовательском ПК не запускался, блокировка Windows и другие команды не выполнялись. Реальная установка поверх пользовательской версии и проверка на физическом iPhone остаются отдельными проверками после обновления пользователем. WebKit-проверка не заменяет физический iPhone.
