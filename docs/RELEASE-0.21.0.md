# XASS 0.21.0

## Музыка на iPhone

- Библиотека, альбомы и исполнители больше не прыгают наверх из-за обновления позиции плеера.
- Синхронный текст прокручивается внутри экрана плеера: текущая строка выходит вперёд, соседние мягко затухают, а паузы между фразами не теряются.
- Произношение и перевод включаются независимо; локальная транслитерация не отправляет текст во внешний сервис.
- Сохранённые перевод и произношение проходят проверку количества строк и таймкодов на сервере и приходят в iOS в том же построчном формате, который рисует плеер.
- Полный экран и компактный плеер получают один и тот же проверенный текст с сервера.
- Исправлен дребезг перехода mini player ↔ Now Playing: жест раскрытия больше не закрывает плеер сразу же.
- При смене устройства XASS останавливает прежний плеер до запуска нового и сохраняет позицию.
- Локальная громкость связана с системной громкостью iPhone; громкость Windows остаётся отдельной.
- Обложку можно выбрать из «Фото» или «Файлов»; она сразу обновляется в плеере, Dynamic Island и на экране блокировки.
- Расшифровка определяет язык автоматически. Кнопка принудительной проверки просит ПК построить точные тайминги даже для уже найденного обычного текста.
- Второй проход расшифровки действительно использует более строгую стратегию распознавания; пустой повторный результат завершает задачу лучшим первым вариантом, а не запускает ещё две тяжёлые попытки.

## Telegram и библиотека

- MP3, WAV, FLAC, OGG, M4A и ZIP, отправленные владельцем напрямую боту, попадают в общую медиатеку.
- Пачка сообщений собирается в один отчёт; повторно присланный файл не дублирует трек.
- ZIP проверяется до распаковки: пути, ссылки, размер, степень сжатия и число файлов ограничены.

## Windows

- Переработан главный экран и музыкальный раздел в едином тёмном интерфейсе.
- В разделе музыки видны отдельно треки на сервере и файлы этого ПК; серверная библиотека загружается в фоне.
- Команды плеера и изменение громкости выполняются вне UI-потока; быстрые движения ползунка объединяются.
- Переход в «Файлы» сразу показывает готовый экран: каталог читается в фоне и отрисовывается порциями без пустого промежуточного кадра.
- Навигация остаётся доступной при масштабе Windows 150–200%; длинные имена не скрывают размер файла, а транспортные кнопки переносятся по фактической ширине окна.
- Серверная музыка поддерживает поиск и страницы по 100 треков без скрытого обрезания библиотеки; строки, громкость и перемотка доступны с клавиатуры.
- Состояния загрузки и ошибки не выглядят как активная кнопка воспроизведения.
- Обложка сохраняется атомарно и привязана к контрольной сумме состояния.
- Серверные подписи, обложка и готовый текст доступны агенту без публикации библиотеки и без передачи ключей в медиа-URL.
- При смене VPN, Wi‑Fi или сети агент сбрасывает старый пул соединений и при необходимости выходит по HTTPS через физический LAN-адаптер без изменения маршрутов Windows.
- Если физических адаптеров несколько, XASS проверяет каждый до настоящего HTTPS-origin с TLS/SNI и сохраняет только рабочий маршрут; проверяются и защищённый DNS-адрес, и системный DNS.

## Передача и безопасность

- При наличии скачанного файла iPhone сначала предлагает его Windows в локальной сети.
- Агент принимает локальный файл только с ожидаемой SHA-256; несовпадение переводит воспроизведение на защищённый серверный поток.
- Несовпадение SHA-256 у серверного файла завершает загрузку ошибкой.
- Поиск текстов отклоняет несовпадающие версии, исполнителей, длительности и подозрительные таймкоды.
- Обложки из Cover Art Archive принимаются только для однозначного официального альбома или EP.
- HTTPS-конфигурация никогда не понижается до HTTP; ключ агента не передаётся чужому origin.
- Код привязки и персональный ключ запрещено отправлять по удалённому HTTP; исключение возможно только для loopback или явного режима локальной разработки.
- Снимок экрана, чтение буфера, скачивание и загрузка файла требуют свежего подтверждения, привязанного к конкретному ПК и параметрам действия; подтверждение загрузки проверяется до чтения тела запроса.
- Ошибки Telegram очищаются внутри клиента: bot token не попадает в traceback, базу, бэкап или диагностический отчёт даже при обрыве потоковой загрузки.
- FastAPI/Starlette и Pillow обновлены до версий без известных аудиту уязвимостей.

## Установка

- Windows: `XASS-Setup.exe` из релиза `agent-latest`.
- iPhone: `XASS-unsigned.ipa` из релиза `ios-latest`; IPA необходимо подписать своим профилем.
- Сервер, Windows-агент и iOS-приложение должны быть одной версии — `0.21.0`.
