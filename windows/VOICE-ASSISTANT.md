# Локальный голосовой помощник XASS — тестовая WinUI-сборка

Помощник работает без сервера XASS и без аккаунта. Поддержаны короткие локальные
команды, русские голосовые ответы Windows и **явно включаемый** фоновый микрофон.
Это тестовая реализация: фактическая работа микрофона, динамиков и качество голоса
на целевом Windows-ПК требуют отдельной проверки.

## Начало работы

Откройте страницу **Помощник**. Если в сборке есть
`runtime/XASS.NativeHelper.exe`, используется встроенный помощник. Резервный путь
Python применяется только при отсутствии этого файла. Для распознавания нужна
заранее установленная локальная папка faster-whisper с `model.bin`; XASS ничего
не скачивает. Без модели можно вводить текст и использовать голосовые ответы.

1. Проверьте пути TLauncher, Minecraft и при необходимости ссылку Discord.
2. Введите команду или нажмите **Записать 6 секунд**. Говорите только после
   сообщения о включённом микрофоне. Одноразовая запись сохранена.
3. Проверьте распознанный текст и предлагаемый результат.
4. Нажмите **Выполнить**. Изменение текста/настроек отменяет старый план.
   Кнопка **Отменить** удаляет план или останавливает текущую операцию.

Уже переданное Windows действие отменой ожидания не откатывается. Помощник
сообщает `dispatched` после передачи Windows, а не утверждает, что приложение
открылось или Minecraft запустился.

## Женский голос и устные ответы

Разверните **Голосовые ответы Windows**. Из установленных WinRT-голосов выбирается
`ru-RU` женский голос; при наличии предпочтение отдаётся Irina/Ирине. Другой
установленный голос можно выбрать вручную. Если русского женского голоса нет,
интерфейс сообщает об этом и не подменяет его молча мужским/иностранным голосом.

Доступны переключатель озвучивания, выбор голоса, проверка звучания, скорость,
громкость и **Остановить речь**. Озвучиваются результаты детерминированного
помощника и подтверждения, а не выдуманный диалог с LLM. Используются только
Windows `SpeechSynthesizer` и `MediaPlayer`. Аудиопоток остаётся в памяти и
освобождается при завершении, остановке, ошибке или закрытии окна. Во время
ответа микрофон помощника закрыт; запуск речи ждёт подтверждения остановки записи.
Остановка во время этой подготовки тоже отменяет будущую речь.

Голоса не устанавливаются, не клонируются, не скачиваются и не отправляются в
облако. Доступность голосов зависит от конфигурации Windows. Настройки действуют
до закрытия окна.

## Фоновый микрофон

Переключатель **Фоновый микрофон** выключен при каждом запуске XASS. Его включение
означает локальное прослушивание стандартного микрофона Windows, пока приложение
открыто, в том числе в свёрнутом окне. Состояние и кнопка выключения видны над
всеми страницами. Закрытие приложения останавливает его дочерний процесс.
Автозапуска скрытого слушателя, службы и фонового прослушивания после закрытия нет.

Говорите обращение и команду **одной фразой**, например: «Джарвис, открой ютуб».
Отдельное «Джарвис» не включает режим ожидания следующей фразы. Неадресованные
расшифровки отбрасываются и не отправляются в UI/планировщик. Аудио не сохраняется,
журналы разговоров не ведутся. Распознавание ограничено сегментами до 10 секунд,
команда — 512 символами. Слишком длинная речь отбрасывается до следующей паузы.

После адресованной фразы микрофон закрывается и слушатель ждёт выполнения или
отмены плана. Он не затирает ручной черновик, не заменяет ожидающий проверки план
и **никогда не выполняет команду сам**. При записи кнопкой, разборе команды и
озвучивании фоновый захват также приостановлен; старое аудио/результаты сбрасываются.
При ошибке микрофон отключается; автоматического цикла повторного включения нет.

Это сегментация тишины и локальный Whisper, а не отдельный маломощный wake-word
движок и не проверка личности. ТВ, запись или другой человек могут произнести
«Джарвис»; поэтому требуется обычная проверка и кнопка **Выполнить**. Модель
загружается один раз на сеанс и остаётся в памяти. Потребление CPU/памяти и
точность в шуме пока не измерены. Музыка, Discord и другие приложения могут
использовать микрофон независимо; XASS не меняет их настройки.

## Поддерживаемые команды

- «Запусти майнкрафт»: проверяет настроенный `forgeai2`, путь игры и Forge 1.20.1;
  запускает только TLauncher без аргументов. Игру запускают в самом лаунчере.
- «Открой ютуб»: передаёт Windows фиксированный адрес YouTube.
- «Открой дискорд»: передаёт Windows зарегистрированный URI Discord.
- «Перейди к каналу Шаурма классическая»: открывает введённую ссылку канала.
- «Подключись к голосовому каналу Шаурма классическая»: отдельное подтверждение;
  **в тестовой версии заблокировано: OAuth/RPC-коннектор не настроен**.

Режим точных команд отклоняет неизвестные, отрицательные и составные фразы.
Существующие ограничения Discord и строгая валидация плана сохранены. Токены
пользователя, selfbot, чтение аккаунта и автоматическая смена разрешений отсутствуют.

## Модель и архитектура

По умолчанию используется детерминированный `RulePlanner`, **не LLM**.
Опциональный `OllamaPlanner` обращается только к `127.0.0.1:11434/api/chat` и уже
имеющейся модели. Он не запускает Ollama и не скачивает модели; живой LLM не был
проверен. Голосовой ответ сам по себе не добавляет разговорную LLM.

Whisper использует CPU/int8, четыре потока, локальный кэш и
`local_files_only=True`. При внешнем Python зависимости указаны в
`pc_client/voice-requirements.txt`; установка окружения вручную остаётся отдельным
действием пользователя. Подготовленную папку модели выбирают в настройках.

- Одноразовый запрос: `AssistantClient` → `assistant_bridge.py` →
  `voice_capture` / планировщик / строгий `LocalExecutor`.
- Фоновый сеанс: `BackgroundVoiceClient` → `background_voice_bridge.py` →
  `background_voice.py` → одна загруженная модель. Двусторонние ограниченные
  JSON-строки: start/paused/ready, pause с подтверждением, resume с номером
  поколения, stop; команды возвращаются только с обращением.
- Речь: `LocalSpeechService` → установленный Windows-голос → поток в памяти →
  `MediaPlayer`. Поток/источник/плеер/синтезатор принадлежат одной отменяемой операции.

Отмена, EOF и смена поколения инвалидируют частичный PCM и устаревшее распознавание.
Перед речью приложение ждёт подтверждения закрытого микрофона; при потере
подтверждения завершает процесс и не начинает речь. Если завершение процесса
нельзя подтвердить, дальнейшая работа с микрофоном блокируется до закрытия XASS.

Музыкальный мост, серверная очередь команд и серверные права не меняются.
Фоновый слушатель не запускает пользовательские программы и не отправляет команды
на удалённые устройства.

## Проверки

```powershell
python -X utf8 -B -m unittest discover -s windows/tests -v
dotnet run --project windows/VoiceLifecycle.Tests/VoiceLifecycle.Tests.csproj -- (Get-Command python).Source
dotnet publish windows/Xass.Native/Xass.Native.csproj -c Release -r win-x64 -p:RuntimeIdentifiers=win-x64 -p:Platform=x64 -o artifacts/windows-native
```

Python-тесты заменяют модель и микрофон фикстурами. .NET-консольный тест использует
только искусственный JSON-процесс: проверяет остановку дочернего процесса, повторные
паузы/возобновления, потерю подтверждения, повреждённые ответы и неадресованные
команды. Он не проверяет WinRT, XAML или физическое аудиоустройство.

Обязательная проверка на Windows до заявления о готовности:

- Сборка XAML/C#, запуск полной папки и наличие всех вспомогательных файлов.
- Женский русский голос есть/отсутствует; ручной выбор, громкость, скорость,
  preview, stop до синтеза и во время речи, пропавшее аудиоустройство.
- Модель отсутствует/повреждена, микрофон запрещён/отключён/занят, шум/тишина,
  длинная речь, «Джарвис» без команды и фраза без обращения.
- Повторные on/off, выключение при загрузке модели/захвате/распознавании,
  закрытие на каждом этапе; в диспетчере задач не остаётся слушатель.
- Ответ динамиками не становится следующей командой; черновик и план не затираются;
  Отменить во время озвучивания preview убирает план; Execute требует нажатия.
- Свёрнутое окно сохраняет только явно включённый сеанс; новый запуск снова OFF.
- Одноразовая запись и существующие команды продолжают работать; нет конкурирующих
  микрофонных процессов при переходе между режимами.
- Измерить CPU/память, задержку, качество и энергопотребление на целевом ПК.
