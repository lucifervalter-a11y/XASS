# Музыка XASS в Discord

Нативный Windows-клиент умеет отправлять текущий трек через локальный Discord Rich Presence. Интеграция по умолчанию выключена. Нужны работающий настольный Discord и **публичный Application ID зарегистрированного приложения XASS**. ID в репозиторий не добавлен: реальная публикация ещё не проверена.

1. Откройте «Музыка» → «Музыка в Discord».
2. Укажите Application ID XASS и нажмите «Сохранить Application ID».
3. Включите «Показывать текущую музыку в Discord».
4. Запустите трек в XASS. Статус подтверждается только после ответа Discord; видимость для других пользователей зависит от настроек активности Discord.

Название приложения берётся из его регистрации Discord. XASS отправляет тип Listening, название, исполнителя и временные метки. Пауза, остановка, ошибка плеера, выключение переключателя и выход из приложения снимают статус. Обычные обновления ограничены одним за 15 секунд; очистка не ждёт этого интервала. Закрытие окна в трей сохраняет работу музыки и выбранной пользователем интеграции.

Никакие токены аккаунта, OAuth-секреты, сообщения, голосовые каналы или контакты не читаются. В IPC не попадают очередь, локальные пути, тексты песен, байты обложки и ссылки с медиатикетами. Обложки никуда не загружаются. Изображение приложения определяется его настройками Discord. Используются только HANDSHAKE, SET_ACTIVITY и ответы PONG; управление голосом Discord в эту интеграцию не входит.

Настройка хранится отдельно в `%LOCALAPPDATA%\XASS.Native\discord-presence.json`: версия схемы, переключатель и публичный ID. Неверный или повреждённый файл отключает публикацию.

Проверки без реального Discord и микрофона:

```powershell
dotnet run --project windows/DiscordPresence.Tests/DiscordPresence.Tests.csproj -c Release
dotnet run --project windows/Appearance.Tests/Appearance.Tests.csproj -c Release
python -m unittest discover -s windows/tests -v
```

Тесты проверяют разрешённые поля, отсутствие приватных полей полного снимка плеера, ограничение частоты, очистку и повторное подключение, повреждённые IPC-кадры, ошибки Discord, сохранение настроек и подписи состояний микрофона. Проверка настоящего профиля Discord остаётся необходимой после настройки собственного Application ID.

Протокол: [Discord RPC](https://docs.discord.com/developers/topics/rpc), [Rich Presence без аутентификации](https://docs.discord.com/developers/discord-social-sdk/development-guides/setting-rich-presence#rich-presence-without-authentication).
